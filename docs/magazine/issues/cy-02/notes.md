## 설계도 (커버)
- thesis: [i+em]은 다른 목소리를 모두 빼고(7→0) 만드는 손은 늘린(12→17) 판이다. 경연 무대의 구조를 정규로 옮겨 왔다
- because: ① 크레딧 첫 줄 12번(h2) ② 1집과의 숫자 비교(h9) ③ Ninetyniiine·편곡 칸의 일치, Yarrr에서 이어진 팀(h2·h11)
- counter: '피처링 0 ≠ 혼자 만듦' → 본문에서 인정하고 '고립이 아니라 선택'으로 답(h5)
- 바이블 검사: 크레딧 먼저 ✓, 가사 0(주제는 보도자료·제목만) ✓, 랩 평가는 '들어 보고 말할 일'로 비움 ✓, 확인 안 된 샘플 0 ✓, 맥락(경력 속 자리·같은 세대) ✓, 응원 한 줄·짧은 끝 문장 ✓, 국내 판 1장 이상 ✓
