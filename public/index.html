Spotify 연결

이 앱의 Client ID가 이미 저장되어 있습니다. 아래 버튼만 누르면 됩니다.

  1. developer.spotify.com/dashboard/create 열기 (로그인 화면이 나오면 로그인한 뒤 이 링크를 한 번 더 누르기) → 앱 이름·설명 아무거나
  2. Redirect URI에 아래 주소를 그대로 넣고, API는 Web API와 Web Playback SDK를 체크 → 저장
  3. 앱 Settings에서 Client ID를 복사 → 이 화면으로 돌아와 붙여넣기 (맞는 값이면 바로 로그인으로 넘어감)
  4. 로그인 → Spotify 화면에서 동의

Spotify 앱 Settings에서 Client ID 옆 복사를 누른 뒤 여기로 돌아와 '붙여넣기'. 앞뒤 글자나 공백이 섞여도 32자리만 골라 넣습니다.

친구용 링크

친구에게는 이 링크를 보내세요. 로그인 버튼만 있고, 크레이트는 Spotify 계정마다 따로 저장됩니다. 먼저 Spotify 대시보드 → 내 앱 → User Management에 친구 Spotify 이메일을, Redirect URIs에 이 링크를 넣어 두세요.
